# DIZGO — Sitio Web Principal

Sitio web de marketing y landing page para **DIZGO App** — la plataforma de gestión financiera para e-commerce y dropshipping en LATAM.

## 🌐 URL
- **Producción:** https://www.dizgo.app
- **App:** https://app.dizgo.app/auth/login  *(pendiente subdominio)*
- **Academia:** https://www.dizgo.app/auth/login

## 🚀 Deploy
Deployado automáticamente en **Vercel** desde este repositorio.
Cada push a `main` actualiza el sitio en producción.

## 📁 Estructura
```
dizgo-home/
├── index.html        ← Página principal (HOME)
├── vercel.json       ← Configuración Vercel
└── README.md
```

## 🔧 Variables
No requiere variables de entorno. Es un sitio estático HTML.
